# Gate-OS Design Concepts

These files are concept artifacts for the Steel Gate shell and are not implemented product screenshots.

## Files

- `tokens.json`: source design tokens.
- `tokens.css`: generated-style CSS variables for mockups.
- `mockup.css`: responsive concept styling with reduced-motion support.
- `index.html`: main desktop concept with persistent seven-environment sidebar.

## Directions

The visual language uses warm paper, charcoal ink, red-orange action color, open typography fallbacks, restrained borders, and a persistent sidebar. The concept supports light/dark/high-contrast tokens, RTL-safe logical properties, keyboard focus, touch-sized controls, and a reduced-motion media query.

The next design checkpoint should add RTL screenshots, a high-contrast rendering, per-environment launcher concepts, first-run/installer states, and a shell technology ADR. All metrics and labels in this concept are illustrative UI content, not system measurements.
